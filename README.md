# Button-LED-interactions
Different Button-Different Act...
---Purpose---
bu proje ledlerin hangi butona basıldığına göre farklı şekillerde yanmasını sağlayan mini devre projesidir.
This project does LEDS flashing different way to which button used.

-JUMPER CABLE(M-M) X 10
-RESISTOR(120 OHM,%1) X 6
-BUTTON X 2
-ARDUINO UNO
-PC-ARDUINO CABLE
-BREADBOARD
